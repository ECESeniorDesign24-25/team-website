# Downloading the Code

To download this repository to your computer, run the following:

1. `git clone https://github.com/ECESeniorDesign24-25/team-website.git`

   

# Local Deployment

To deploy the application locally, run the following:

1. `./setup.sh`
2. `./run.sh`

This will run the website in your local browser.


# Remote Deployment

To deploy the application remotely, run the following:

1. `./deploy_myweb.sh`

This will redeploy the application to the UIowa MyWeb server


# Changing Password

To change the password, run the following:

1. `./update_pass.sh`

This will update the password file and re-deploy the app automatically
